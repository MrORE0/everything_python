Anchor 3

The Memory Model — "Pointers"

Every value is an object living somewhere in memory. A variable is just a name pointing at it.

a = [1, 2, 3]
print(id(a))   # the object's address, basically

C/Java folks: yes, this is basically a pointer.

Anchor 5

Shallow vs. Deep Copy

import copy

original = [[1, 2], [3, 4]]
shallow   = copy.copy(original)
deep      = copy.deepcopy(original)

shallow[0].append(99)
# original[0] changed too — shallow copy only copies
# the outer list; inner lists are still shared
Classic trap: list(x) and x[:] are also shallow copies — don't let the syntax fool you. Nested mutable data always needs deepcopy.
Anchor 5 — rule of thumb

When to use shallow vs. deep

Data shape Example types Use Why
Immutable int, str, tuple either Can't mutate — sharing is safe
Flat mutable list of ints / strings shallow Elements are immutable — no hidden sharing danger
Nested mutable list of list/dict, objects with state deepcopy Inner objects are shared by shallow — mutation bleeds back

Rule: if the elements can be mutated in-place, shallow copy is not enough.

Anchor 6

Garbage Collection

Reference counting handles most objects instantly. A cycle detector runs periodically to catch the rest.

A
B

A → B → A: each holds the other's refcount at 1. Nothing external points to either. Refcount never hits zero.

Anchor 6 — under the hood

Refcounting vs. Cycle Detector

Mechanism What it asks Blind spot
Refcounting "Is anyone pointing at me?" Can't tell live caller from a dead object in the same cycle
Cycle detector "If I subtract all internal refs, does count hit zero?" Slower — runs periodically, not instantly
Cycle detector simulates stripping out intra-group references — if the adjusted count reaches zero, the whole group is unreachable and gets swept at once.
