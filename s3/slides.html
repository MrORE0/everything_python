Part 1 · Anchor 1 — a realistic use

A dictionary of functions

A chat bot gets the command as text. The dictionary picks the function.

def greet(name):
    return f"Hello, {name}!"

def goodbye(name):
    return f"Bye, {name}."

commands = {"hi": greet, "bye": goodbye}

message = "hi"                  # imagine this came from a user
commands[message]("Steve")      # 'Hello, Steve!'
New command = one new line in the dictionary. No if/elif chain to grow.
Part 1 · Anchor 2

Closures

def make_counter():
    count = 0
    def increment():
        nonlocal count
        count += 1
        return count
    return increment

c = make_counter()
c(); c(); c()
c.__closure__[0].cell_contents
  • An inner function remembers the variables around it
  • Each call to make_counter gets its own memory
  • It stores them in a special attribute called __closure__
  • The inner function keeps a reference, not a copy, to those variables
Closures are used in functional programming, event handling and callback functions, wherever you need to retain some state without using global variables.
Part 1 · The connection

A decorator is a closure that remembers a function

Closure

def make_multiplier(m):
    def inner(x):
        return x * m
    return inner

remembers a number: m

Decorator

def timed(func):
    def wrapper(*args, **kwargs):
        return func(*args, **kwargs)
    return wrapper

remembers a function: func

Same shape: the outer function returns an inner function that uses the outer function's variable. timed has already finished by the time wrapper runs, and wrapper still finds func because it is a closure.
Part 1 · Anchor 3

A decorator takes a function, returns a function

def timed(func):
    def wrapper(*args, **kwargs):
        start = perf_counter()
        result = func(*args, **kwargs)
        print(perf_counter() - start)
        return result
    return wrapper

@timed
def slow_add(a, b): ...

@timed is shorthand for:

slow_add = timed(slow_add)

Part 1 · Demo

One line turns exponential into instant

from functools import cache

@cache
def paths(r, c):            # ways to cross an r x c grid
    if r == 0 or c == 0:
        return 1
    return paths(r - 1, c) + paths(r, c - 1)

12 x 12, no cache

~0.4 s
millions of repeated calls

12 x 12, with @cache

~0.000 s
each subproblem solved once — that is dynamic programming
Part 1 · Anchor 4

partial: pre-fill arguments

from functools import partial

def mult(m, num):
    return m * num

double = partial(mult, 2)      # m is now fixed to 2
double(5)                      # 10

binary_to_int = partial(int, base=2)
binary_to_int("1010")         # 10
partial builds a new function from an old one with some arguments already filled in.
Part 1 · Anchor 4

map, filter, reduce

ToolWhat it doesIn Python, usually write
map(f, xs)apply f to every item[f(x) for x in xs]
filter(f, xs)keep items where f is true[x for x in xs if f(x)]
reduce(add, xs)fold the items into one valuesum(xs)
Comprehensions are the idiomatic choice. Know map, filter and reduce for reading other people's code.
